# Building Bridges 2026 班级数字展馆

“科技与艺术”课程的班级共创网站。四个小组共同提交人物、作品、课堂故事与未来留言，教师审核后统一展示。

## 当前状态

此仓库是从原 ChatGPT Sites 项目整理出的**平台无关迁移版**：

- 已保留首页、学生提交页和教师审核台的视觉界面；
- 已移除 ChatGPT 专属登录、D1、R2 和个人管理员邮箱；
- 不包含任何学生提交数据或上传图片；
- 当前云端提交接口为安全占位状态，配置新数据库前不会保存内容。

## 本地查看

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

然后访问：

- 首页：`http://localhost:3000`
- 学生提交：`http://localhost:3000/contribute`
- 教师后台：`http://localhost:3000/admin`

## 配置文件

复制 `.env.example` 为 `.env.local`，再填写自己的配置。请勿把 `.env.local`、管理员密码或云服务密钥上传到 GitHub。

## 迁移计划

1. 将本仓库上传至 GitHub。
2. 从腾讯云 EdgeOne 导入该仓库，先验证公开页面可以正常访问。
3. 创建云数据库，保存文字、署名、分组和审核状态。
4. 创建对象存储，保存 JPG、PNG、WebP 图片。
5. 为教师后台增加安全登录与会话。
6. 接通提交、编辑、审核、删除和图片读取接口。
7. 使用不同网络与手机完成测试后，再正式交给学生。

## 数据与隐私

- 学生不需要注册账号；
- 公开页面只展示教师审核通过的内容；
- 不建议收集学生手机号、邮箱等无关信息；
- 图片上传应限制类型和大小；
- 数据库与图片应定期导出备份；
- 课程结束后应决定保留或删除学生数据。
